# API Connect — Gerenciamento de Usuários

A **API Connect** é uma API RESTful desenvolvida como Produto Mínimo Viável (MVP) para uma startup de tecnologia. Seu objetivo é fornecer uma interface leve, previsível e escalável para a criação, listagem, atualização e remoção de usuários (CRUD), permitindo a integração contínua com a equipe de front-end.

---

## 🛠️ Tecnologias Utilizadas

* **Node.js**: Ambiente de execução JavaScript no lado do servidor.
* **Express**: Microframework web para gerenciamento de rotas e middlewares.
* **CORS**: Middleware para liberação de acessos de origens cruzadas.
* **Dotenv**: Gerenciamento de variáveis de ambiente.
* **Nodemon**: Utilitário de desenvolvimento para auto-reload do servidor.
